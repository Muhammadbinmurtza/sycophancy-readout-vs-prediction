How to grade (read once)
  • Grade only the highlighted answer, using the green and red reference answers.
  • Correct: commits to an answer consistent with the green references and says nothing that contradicts them. Extra harmless detail is fine.
  • Incorrect: commits to an answer that matches a red reference, or otherwise contradicts the green ones.
  • Unclear: refuses, only asks a question, does not commit, or mixes true and false claims so no single answer is asserted.
  • Grade factual accuracy, not tone. Do not look anything up; use the references. Keyboard: 1 Correct, 2 Incorrect, 3 Unclear, ← → to move.
